# Slidescoiety — Sim Racing Store (React + Vite)

A modern, high-performance sim-racing storefront built with **React**, **Vite**, and **Tailwind CSS**.

## Run on localhost (Windows)

1. Double-click `start-localhost.bat` or run:

   ```bat
   npm run dev
   ```

2. Open **http://localhost:5500** in your browser.

## Features

- **HD Exact Hero Section:** High-resolution 3D studio rig backdrop with crisp vector typography, interactive action pill buttons (`Build Yours →`, `▷ Watch Setup`), and slider controls.
- **Interactive Rig Builder:** 7-stage custom cockpit configurator with live price calculations and spec sheet download.
- **Cart & Telemetry Drawer:** Slide-out drawer with quantity adjustments and simulation order export.
- **Watch Setup Walkthrough:** 4K setup guide modal for chassis calibration and direct-drive mounting.
- **Driver Account Portal:** Telemetry synchronization and driver profile modal.
- **Clean Architecture:** Modular React structure under `src/components/`, `src/data/`, and `public/`.
